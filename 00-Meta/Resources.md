## Courses & Platforms

### DSA & CP

- **Neetcode.io** — Best structured LeetCode roadmap. Start here.
- **Codeforces** — Contest practice. Target Div.2 A/B/C.
- **LeetCode** — 150 curated problems (Neetcode 150 list)
- **CSES Problem Set** — Best for CP fundamentals (free)

### CS Fundamentals

- **CS50 by Harvard** (cs50.harvard.edu) — Free. Best intro to OS + networking
- **Hussein Nasser on YouTube** — Networking, databases, backend engineering
- **ByteByteGo** (bytebytego.com) — System design. Newsletter + YouTube

### Frontend

- **Josh W Comeau** (joshwcomeau.com) — CSS, React, performance. Best frontend blog
- **Kent C. Dodds** (kentcdodds.com) — Testing, React patterns
- **Next.js Docs** (nextjs.org/docs) — Official docs. Actually read them.

### System Design

- **ByteByteGo YouTube** — Free system design videos
- **roadmap.sh/system-design** — Free visual roadmap
- **Exponent** — Mock interviews (paid but worth it)
